# Meu Cão Descomplicado — Simbas Pet

Landing page oficial de alta conversão para o infoproduto **Meu Cão Descomplicado** da Simbas Pet.

## 📦 Conteúdo da Coleção
- **12 Guias Digitais** independentes para situações do dia a dia (Passeios, Ansiedade por separação, Xixi fora do lugar, etc.)
- **72 Cards de Apoio** com orientações práticas para consulta rápida
- **Fichas de Rotina e Registro** para acompanhamento doméstico e veterinário
- Arquivos em PDF de alta resolução para consultar na tela ou imprimir

## 🚀 Arquitetura Frontend
- **HTML5 Semântico**: Estrutura acessível com metadados Open Graph.
- **Vanilla CSS3**: Design system responsivo, arquitetura mobile-first, animações de alta performance (60fps) e contraste WCAG AAA.
- **Vanilla JS**: Lightbox/Zoom para páginas e cards, carrossel dinâmico e seletor interativo dos 12 volumes. Zero dependências externas ou render-blocking.
